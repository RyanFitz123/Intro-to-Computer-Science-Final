This is a turn-based fighting game displayed through text.
It plays similarly to traditional RPG combat systems.
You play against a computer opponent. 
There are 3 different characters in total each with 2 different moves and an ultimate move. 
The ultimate move charges with each normal move used. 
Some moves will charge it faster. Damage also differs between moves. 
Health is different for each character as well. 
After finishing a battle you can choose a new character, replay with the same characters, or quit. 
All the options are chosen in a menu using the “A”, “B”, “C”, and “D” keys.
